# LessonBoard: урок по аудио и видео в HTML

## GitHub Pages

В репозиторий сайта включите `index.html`, `student.html`, `teacher.html`, `app.js`, `shim.js`, `config.js` и всю папку `images/`, включая `images/presentation/`.

Не добавляйте `users.json` с личными аккаунтами: GitHub Pages публичен, и этот файл становится доступен каждому посетителю. Не добавляйте в публичный репозиторий ключи и пароли. Личные учётные данные создаются локально через `make-users.html`; полученный `users.json` нужно хранить и публиковать только с учётом того, что сайт полностью публичный.

## Google Apps Script

`Code.gs` предназначен для Apps Script, а не для GitHub Pages. Установите собственный секрет `TEACHER_KEY` в **Настройки проекта → Свойства скрипта** в Apps Script. Не записывайте ключ в файл и не публикуйте его.

## Разделы сайта

Ученик и учитель видят общие вкладки «Урок», «Лекция», «Задания», «Тест» и «Рефлексия». В карточках заданий ученик открывает ссылки и материалы, отмечает выполнение, а прогресс сохраняется вместе с результатами. Во вкладке «Учитель» доступны журнал и редактор урока.

Учитель может менять тему и цели, редактировать разделы лекции и добавлять к ним фотографии, создавать карточки заданий с несколькими ссылками, фотографиями и баллами, менять вопросы теста и формулировки рефлексии. После сохранения локально изменения увидит только этот браузер; для общей публикации нужен настроенный облачный доступ.

Лекция и тест посвящены вставке аудио и видео в HTML и используют 18 иллюстраций из предоставленной презентации.
